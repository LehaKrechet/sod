# ПО «Сод» — ускоренная версия

Децентрализованный P2P-прототип UDP Multicast для Linux. Каждый экземпляр равноправен, самостоятельно обнаруживает соседей, инициирует циклы и отвечает на запросы.

## Сборка

```bash
sudo apt update
sudo apt install build-essential
make
```

Сборка использует C++17, `-O3` и `-march=native`. Для переноса бинарника на процессоры другой модели удалите `-march=native` из Makefile и пересоберите.

## Запуск

На каждом ПК укажите адрес его собственного сетевого интерфейса:

```bash
./sod --iface 192.168.1.10
```

По умолчанию Multicast `239.0.0.1:5000`, период между циклами — 1000 мкс (1 мс). Пример более частых циклов:

```bash
./sod --iface 192.168.1.10 --interval-us 500
```

Допустимый интервал: 100..10000000 мкс. Слишком малый период может увеличить конкуренцию за CPU и сеть.

## Изменения

- Интервал по умолчанию уменьшен с 10 мс до 1 мс.
- Оптимизация сборки `-O3 -march=native`.
- Увеличены буферы UDP-сокета.
- Цикл измерения отделён от обновления интерфейса: dashboard работает в отдельном потоке и обновляется 4 раза в секунду.
- Панель показывает last/average/min/max, число циклов, превышения 200 мкс, неполные циклы, ответы и активных соседей.
- Диаграмма последних 80 измерений стала компактнее и использует цветовую индикацию.

## Интерпретация 200 мкс

Измеряется время от отправки Multicast-запроса до получения ответов от всех известных активных соседей либо до таймаута 200 мкс. Это целевой порог, не гарантия. Результат зависит от ОС, планировщика, CPU, драйвера, коммутатора, количества узлов и нагрузки.

`--interval-us` — пауза после завершения измерительного цикла, а не гарантированная частота завершения циклов. UDP Multicast не гарантирует доставку; счётчик incomplete означает, что в измерительном окне не получены все ожидаемые ответы.

Для теста используйте проводной Ethernet в одном L2/VLAN, разрешите UDP/5000 в firewall и сравнивайте измерения при одинаковой нагрузке. Протокол не содержит аутентификации/шифрования; используйте только в доверенной лабораторной сети.
