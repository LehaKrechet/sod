# SOD Multicast — диагностика задержек отправки

Эта диагностическая версия сохраняет обмен UDP multicast и измеряет дополнительную детализацию отправки при циклах, превышающих 200 мкс.

## Сборка

```bash
sudo apt update
sudo apt install -y build-essential cmake
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

## Запуск

```bash
sudo ./build/sod_multicast config.ini
```

Настройте `node_id` и `interface_ip` отдельно на каждом компьютере, остальные сетевые параметры должны совпадать. Для ограниченного теста задайте `max_cycles`, например 10000. Для теста 2 КБ оставьте `payload_size_bytes=2048`.

## Файлы диагностики

После ограниченного теста:

- `over200_diagnostics.csv` — сводная запись каждого цикла, превысившего 200 мкс: измерение TX, длительность всей функции отправки, сумма, минимум и максимум длительности вызовов `sendto()`, количество вызовов и ошибок, задержка до входа в отправку, RX и post-RX, CPU и timestamp.
- `over200_sendto_details.csv` — строка на каждый `sendto()` из проблемного цикла: индекс фрагмента, время вызова в микросекундах, возвращённое значение и errno.

Подробные замеры `sendto()` добавляют небольшую нагрузку и влияние на тайминг. Сборка предназначена для диагностики, а не для подтверждения гарантированного времени real-time.


CSV-логирование и диагностика превышений 200 мкс удалены. Программа выводит только текущую статистику/гистограмму в терминал.
